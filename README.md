# CIP investor data room — leadership preview

Public preview: https://danicollante.github.io/cip-investor-data-room-review/

Entooma Sidai is populated with current working data, model figures, citations and a 151-entry document index. The other 16 pipeline projects are visible but unavailable.

The Entooma overview includes five GIS layers. The boundary on file is 652,022 ha and does not match CIP's confirmed 500,000 ha; it is not the final project perimeter. Map tiles load from OpenStreetMap.

Accounts, permissions, NDA, invitations, requests and activity are simulated in the browser. No original documents are delivered. Data files in this static site are publicly readable.

Open the root URL to view the site. Rebuild from the working repository with `python3 docs/investor-data-room-preview/build_full_review.py`. Review and commit each client-facing update in this separate repository.
